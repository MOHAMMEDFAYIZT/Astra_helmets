# Astra Helmets — Frontend UI Showcase

A frontend-focused visual concept for a helmet storefront, built to explore product presentation and e-commerce interface design.

**Project type:** UI showcase / frontend concept

## About

Astra Helmets is a design-oriented frontend project. It is included as an example of interface and visual-development work, not as a complete e-commerce system.

The repository currently presents a single-page React application. Backend services, real product inventory, authentication, order processing, and payment functionality are outside the scope of this showcase.

## Technology

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Run locally

### Requirements

- Node.js compatible with the Vite version in this project
- npm

### Setup

```bash
git clone https://github.com/MOHAMMEDFAYIZT/Astra_helmets.git
cd Astra_helmets
npm install
npm run dev
```

Create a production build:

```bash
npm run build
```
